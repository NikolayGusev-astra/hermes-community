# hermes-bundle/1 — что заявляет автор набора

Схема версии 1. Манифест лежит в корне bundle и обязателен: без него гейт не
запускает проверки, потому что нечего сверять с содержимым.

```yaml
schema: hermes-bundle/1

# Идентификатор: только a-z, 0-9 и дефис. Совпадает с именем каталога в bundles/.
name: market-analyst

# Как карточка называется на сайте.
title: Маркет-аналитик для маркетплейсов

# Одно-два предложения: что решает набор. Показывается в каталоге.
summary: Считает юнит-экономику и следит за ценами на Ozon и WB.

# Лицензия самого bundle. Список разрешённых — в tools/gate.py.
license: MIT

authors:
  - name: Иван Петров
    github: ivanpetrov   # аккаунт GitHub, не почта

tags: [marketing, marketplace, pricing]

# Что набор трогает при работе. Это риск-класс карточки: по нему читатель
# решает, ставить ли. Заявлять честно — ревьюер сверяет с содержимым.
risk:
  network: true        # ходит в интернет
  credentials: true    # нужны ключи/токены
  money: false         # трогает деньги или сделки
  filesystem: true     # пишет файлы вне своего каталога
  shell: false         # запускает команды оболочки

# Файлы поведения агента. Хотя бы один из soul/agent обязателен.
entry:
  soul: soul.md
  agent: AGENT.md
  skills:
    - skills/unit-economics

# Минимальная версия Hermes Agent, на которой набор проверен.
compat:
  hermes: ">=1.0"

# Необязательно: чем автор это проверял. Свободный текст, одна-две строки.
tested_on: Hermes Agent 1.2, Windows 11 и Ubuntu 24.04
```

## Почему risk-класс в манифесте, а не выводится автоматически

Сканер видит конструкцию, но не назначение. `requests.get` в скилле про погоду и
`requests.get` в скилле, который торгует на бирже, выглядят одинаково, а цена
ошибки отличается на порядок. Автор заявляет класс, ревьюер проверяет заявление,
карточка показывает заявленное. Расхождение между заявленным и найденным —
отдельная причина отклонить PR.

## Почему версия схемы в манифесте

Когда правила поменяются, старые наборы не должны молча пройти по новым
правилам. Гейт читает `schema` и применяет ту версию проверок, которая
соответствует заявленной.
