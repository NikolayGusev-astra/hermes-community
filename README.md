# hermes-community

Публичный каталог наборов для Hermes Agent. Люди приносят свои `soul.md`,
`AGENT.md`, скиллы и профили, репозиторий их проверяет и публикует карточку.

**Единица вклада — bundle.** Один каталог, в котором персона, процедуры и
конфиги лежат вместе с манифестом. Не отдельный скилл и не отдельный `soul.md`:
по отдельности нечего ревьюить.

## Как это устроено

| Слой | Где | Что делает |
|---|---|---|
| Вклад | `bundles/<name>/` | автор приносит набор через pull request |
| Гейт | `tools/gate.py` | детерминированная проверка, одинаково локально и в CI |
| Ревью | CODEOWNERS + PR | человек читает смысл: автоматика видит конструкцию, но не намерение |
| Карточка | сайт hermes-agent.ru | читает собранный артефакт, контент не хранит |

`main` защищён: прямой push запрещён, merge только через PR после зелёного гейта
и ревью.

## Как поделиться своим набором

Самый короткий путь — агентом:

```bash
# установить скилл-упаковщик
cp -r packager ~/.hermes/skills/bundle-packager
```

Дальше скажи агенту: «хочу поделиться своим набором в hermes-community». Скилл
`bundle-packager` задаст вопросы блоками, соберёт `manifest.yaml`, `soul.md`,
`AGENT.md` и скиллы, прогонит гейт и откроет PR.

Руками:

```bash
git clone https://github.com/<owner>/hermes-community.git
cd hermes-community
cp -r bundles/_template bundles/my-bundle
# отредактировать manifest.yaml и содержимое
python tools/gate.py bundles/my-bundle
git switch -c bundle/my-bundle
git add bundles/my-bundle && git commit -m "bundle(my-bundle): ..."
git push -u origin bundle/my-bundle
gh pr create
```

## Что проверяет гейт

- манифест парсится, обязательные поля на месте, объявленные пути существуют;
- лицензия из разрешённого списка;
- размер: не больше 300 файлов и 5 МБ;
- секреты: `gitleaks` плюс собственные регулярки;
- приватные адреса, корпоративные домены, личные пути;
- невидимые символы и инструкции в HTML-комментариях;
- каждый скилл через `skills_guard` из Hermes Agent;
- **сверка манифеста с содержимым**: заявленный `risk` против найденного в тексте.

Гейт запускается локально и в CI одним и тем же скриптом. Если локально `OK`, а в
CI `FAIL` — это дефект репозитория, заводите issue.

## Риск-класс

В манифесте пять флагов: `network`, `credentials`, `money`, `filesystem`,
`shell`. По ним карточка показывает, что набор трогает. Наборы с `money: true`
(торговля, маркетплейсы) публикуются только карточкой: код читают отдельно, а не
ставят по описанию.

## Структура репозитория

```
bundles/            наборы; _template — образец
packager/           скилл, который собирает bundle вместе с автором
tools/gate.py       гейт приёма
docs/               манифест, правила ревью
.github/workflows/  CI
```
